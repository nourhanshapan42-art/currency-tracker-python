# 📊 Sales Data Analyzer

A Python tool that processes sales data from a CSV file, performs basic analytical metrics, and automatically generates a structured summary report.

## 🚀 Features
- Total Revenue Calculation: Computes overall sales revenue automatically.
- Top Performers: Identifies the most sold product and the item generating the highest revenue.
- Category Breakdown: Aggregates total sales by product categories.
- Automated Reporting: Exports all key findings directly into a formatted sales_summary.txt file.

## 📁 Project Structure
- sales_data.py: Main Python script for data processing and report generation.
- sales_data.csv: Input CSV dataset containing raw sales records.
- sales_summary.txt: Generated output summary report.
